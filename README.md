# Internship Portfolio — Aliu Faridat Ajoke

This repository contains a simple portfolio site with four internship case studies created from the DecodeLabs internship projects.

Quick steps to publish
1. Create a new GitHub repository for your portfolio (or use one you already created).
2. Copy the files and folders from this template into the repository root:
   - index.html
   - styles.css
   - README.md
   - projects/project1.md
   - projects/project2.md
   - projects/project3.md
   - projects/project4.md
   - Optional: add an assets/ folder with screenshots or diagrams
3. Commit and push to the `main` branch.
4. Enable GitHub Pages: Settings → Pages → Branch: `main` / Folder: `root` → Save.
5. Your site will be available at `https://<your-username>.github.io/<repo-name>/` (or at a custom domain if configured).

Notes for editing case studies
- Each project Markdown file includes sections for Summary, Role, Tools, Approach, Technical notes, Results, and Artifacts & links.
- Replace placeholder text like timelines or numbers if you want to be more specific.
- To show screenshots/diagrams, add images into `assets/` and reference them in the project's Markdown (e.g., `![diagram](../assets/diagram.png)`).
