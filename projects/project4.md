# Project 4 — Data Visualization

Tagline: Interactive Power BI dashboard showcasing product performance, monthly trends, and payment-method shares.

Summary
Built a single-page Power BI dashboard that visualizes the cleaned orders dataset—showing orders by product, monthly order trends, and payment method distribution. The dashboard includes captions and a key-insights panel to communicate findings clearly.

Role & timeline
- Role: Data Analytics Intern — Aliu Faridat Ajoke  
- Timeline: Internship project (add exact dates or duration)

Tools & tech
- Microsoft Power BI Desktop (Clustered column, Line chart, Pie chart)

Dashboard contents
- Bar chart: Orders by Product (top products called out)
- Line chart: Monthly Order Trend (Jan 2023 – Jun 2025)
- Pie chart: Orders by Payment Method
- Key Insights panel and caption labels for each visual

Key findings shown on the dashboard
- Printer: 181 orders (top)
- Tablet: 179 orders
- Chair: 178 orders
- Monthly order volume between ~27 and 53
- Online and Cash are top payment methods
- Cancelled + Returned orders make up over 40% of orders

How to open the dashboard
- Power BI file: `DecodeLabs Project 4 - Dashboard.pbix` — open in Power BI Desktop and refresh data from the Cleaned_Data sheet in the Project 2 workbook.
